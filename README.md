# My Personal Website

A modern, responsive personal website ready to be hosted on **GitHub Pages**.

## 📁 Project Structure

- [`index.html`](index.html): Main HTML structure containing the header, hero section, about section, skills, projects, and contact area.
- [`style.css`](style.css): Responsive CSS styling with light & dark mode themes.
- [`script.js`](script.js): JavaScript for theme toggle (light/dark mode), dynamic footer year, and responsive mobile menu.

## 🚀 How to Host on GitHub Pages

1. Target repository: `https://github.com/sophia8hu/sophu.github.io`
2. Push `index.html`, `style.css`, and `script.js` to this repository.
3. In GitHub repo **Settings** > **Pages** > Select `Deploy from a branch` > Choose `main` branch > Save.
4. Your website will be live at `https://sophia8hu.github.io/sophu.github.io` (or `https://sophu.github.io` if that's your domain / user site)!
